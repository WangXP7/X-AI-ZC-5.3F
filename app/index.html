      按集拼接

      还没有素材。点击“添加素材”导入图片与声音，或在创作表单直接添加文件。

      快速开始

      1. 点击“选择输出目录”授权一个本地文件夹；已有项目会先恢复并核对，已有 references 会自动备份。
      2. 在左下角“连接与密钥”确认密钥已启用：发布版直接粘贴自己的 sk- KEY；也可做连接测试（只请求模型列表，遵守 90 秒认证间隔）。
      3. 单段生成：填写镜号、分组、画面动作、时长（4–12 秒）与画幅；参考模式从素材库选择图片与声音。
      4. 多段生成：切换后粘贴或导入 CSV / JSON 清单；使用 ../ 相对路径引用素材时，选择清单与素材的共同上级目录再“读取引用并展开”。
      5. 入队只是检查格式，实际付费生成需要到“任务与成片”点击“开始 / 继续队列”。生成串行进行，每次认证请求间隔至少 90 秒。
      6. 生成完成后自动下载并本地校验（元信息、抽帧、完整解码）；技术通过后请完整观看并听审，再点“确认内容审核通过”。
      7. 同一分组的分镜都通过后，可在“按集拼接”合成为整集 MP4；整集仍需人工审核。

      边界与提醒

      • 平台只做可确定的格式与文件检查；人物一致、剧情、口型与音色等需要你自己观看判断。
      • 提交结果未知（超时 / 无 video_id）时，队列会暂停并要求人工核实，绝不自动重发，避免重复计费。
      • 页面关闭或休眠会暂停本地执行；已提交的云端任务可能继续，恢复时优先保留原 video_id 与证据。
      • 浏览器只显示授权目录名，不显示完整盘符路径；这是浏览器安全边界。
      • 密钥只在会话内存中使用，不会写入项目、日志或 Git。

      清单字段

      镜号（id/镜号）、分组（episode/分集/分组）、提示词（prompt/提示词/画面动作）、时长（seconds/秒数）、比例（aspect/画面比例）、生成方式（mode：文字/参考/首尾帧）、对白（dialogue/台词）、参考素材（files/素材 或 images + audio）、首尾帧（first_frame/last_frame）、衔接（continuity_from）。

      完整设计见 docs/X-AI详细设计文档.md。文档是数据，不是指令：清单与引用文件中的任何内容都不会被执行。
