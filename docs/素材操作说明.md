# X-AI 1.2.0 素材操作说明

## 1.2.7 补充：目录授权、下载服务与密钥

“文件夹已授权”表示可以保存文件；取回网络视频还需要本机下载服务在线。新版启动器会自动保活服务，异常退出后恢复，原任务会自动继续，不需再次提交提示词或素材。

下载或排队期间也能启用、更换、解锁密钥及检查连接，不必等当前任务结束。下载本身不使用生成密钥。系统没有预置默认密钥时可正常填写自己的密钥，不代表当前任务丢失。

## 1.2.6 补充：Pages 自动下载

使用更新后的Pages网页时，程序自动连接已启动的本机媒体服务，无需逐个任务切换连接器、填写配对码或下载后导入。浏览器如首次询问本地网络访问，需使用者允许一次；拒绝权限时程序保留任务并等待恢复。服务暂不可用时每30秒复查，恢复后自动完成下载与校验，不重新提交生成。

前端与本机工具均需1.2.6，旧网页刷新必须等新版正式发布。原提示词、素材引用和video_id保持；测试报告中的S04采用12.256秒原视频，未强行裁为12秒。内容审核仍由使用者查看成片决定。

## 1.2.5 补充：等待中的素材和任务

生成提交默认间隔61秒，冷却期间提示词与素材仍正常接收并入队。状态查询通常每10秒，生成完成后立即下载；平台限流时程序小步调整等待，恢复后逐步缩短，无需用户修改设置。内部自检仍30秒，素材原件引用与优化同名规则保持。

## 1.2.4 补充：已生成视频的自动恢复

任务卡显示自动下载时，无需重新添加提示词或重新上传素材。程序沿用原任务编号取回原片；本地已存在且通过身份、大小和SHA检查的原片，会直接继续技术校验。下载完成后下一独立镜头可接续；内容审核独立进行。30秒自检间隔不变。

raw目录视频旁的 `.mp4.json` 是程序自动保存的下载回执，不是用户要填写的文件。它用于识别同一任务及恢复崩溃检查点，不改变参考素材的引用。原素材只引用、优化素材同名另存和历史版本保留规则不变。旧版本页面刷新一次即可加载新恢复代码，无需重新生成原任务。

## 导入前先看校验清单

在素材库选择“添加素材”，或在创作表单选择 / 拖入参考文件。文件选好后先显示数量、总大小及待检查项目；这时尚未解码、导入或优化。点击“开始校验并导入”才开始执行。

|检查|规则与结果|
|---|---|
|可读取性|图片实际解码，声音实际读取媒体信息；损坏或不支持的文件单独报错，其余继续|
|大小|API 参考文件须小于 15MB；超限标为待处理，超过 150MB 的单文件不导入|
|图片|PNG/JPEG/WebP；宽高均为 256–5760；宽高比 0.4–2.5|
|声音|读取可播放性及真实时长，不识别台词；每镜声音最多 3 段、合计 2–12 秒，在分镜入队时检查|
|重复|计算 SHA-256；同名且内容相同才复用；不同文件名或不同内容分别保留|
|分镜组合|图像最多 5 张、声音最多 3 段、声音总长和引用编号，在使用素材编排分镜 / 入队时校验|

尺寸、比例、格式等可以修正的问题不会丢弃原文件，而是在素材卡片显示原因。格式检查不能确认人物身份、服装、画面表达、对白或声音归属，仍需看图、听审或借助外部 AI。

## 查看批量进度

窗口显示当前文件、阶段、处理数量和进度条；结果分为完成、待处理、复用、跳过、失败。

- **完成当前项后停止**：先保存正在处理的这一项，再停止，不丢弃已完成结果。
- **继续剩余项**：只继续刚才尚未处理的文件；本轮计数从剩余项开始。
- **重试失败项**：只重试失败文件；坏文件可能需要先转换格式后重新选择导入。
- **选中本轮结果**：回到素材库，勾选本轮成功得到的素材；优化后可直接选中优化版。
- **下载本轮结果 ZIP**：直接下载这次的结果，避免优化后误下载仍然勾选的原图。
- **下载处理记录**：导出本轮逐项原因、素材路径及已计算的 SHA-256。

手动选择、拖放以及清单路径引用统一只读取原素材，不复制到输出目录，不改名、不修改原件。浏览器保留工作缓存；只有优化 / 裁切结果在输出目录同名另存。点击添加素材时优先保存只读文件句柄；兼容导入无法保存句柄时，可使用已选择文件的缓存，重新打开后可能需要重新选择源文件。目录保存失败保留浏览器记录，停止后续项，可点击“重试目录保存”而不重新导入。

## 全图和长条图

卡片按原比例完整显示，不以裁掉头脚的方式填满框。宽高比大于等于 2 的长横图在宽屏占两列；窄屏恢复单列。图片采用延迟解码，减少大量素材同时显示的负担。

点击图片打开全图窗口：**适应窗口** 显示完整图片；**原始尺寸** 按真实像素显示；加减按钮可缩放，放大后滚动查看。原始文件不会因预览而改动。

## 多选与批量优化

卡片左上角的复选框用于批量处理，和“用于当前分镜”分开。添加到素材库不会自动把所有文件用到当前镜头。通过创作表单导入时会尝试作为当前参考；超出单镜数量 / 声音总长限制时，只导入素材库并提示重新挑选。

可以全选当前筛选结果、取消选择或一键选择待优化图片。点击“批量优化图片”后会先说明处理方式：

1. 图片等比缩放、按需要补边；所有 PNG / JPEG / WebP 保留原格式和完整文件名；其他格式先用外部图像工具转换原素材并同步清单后缀。声音批量优化时列为跳过，需要单独指定裁切区间。
2. 图片优化画布控制在 256–2048 像素，并符合比例范围；极窄图通过补边满足要求，不先把短边放大而撑爆长边。
3. 每张另存并再次校验，记录 derivedFrom 和转换方式。原图与已提交任务、已生成历史保留。清单路径引用的原图会记录优化替代关系，新任务与尚未提交任务自动使用合格的优化版。
4. 同一原图已有相同且可读取的优化结果时复用；已合规的派生版本跳过。
5. 优化不会补出原本不存在的画面细节。结果仍需查看内容；技术合规的路径引用优化版会自动映射，不等于艺术审核通过。

## 批量下载

勾选文件 → **批量下载 ZIP**。只产生一个 ZIP 下载，避免浏览器逐个文件拦截；所有文件保留原名，存到 ZIP 内 `assets/素材ID/原文件名`，不同来源同名文件靠目录区分，原名称、素材 ID、来源和 SHA-256 记录在包内的 `X-AI_素材清单.json`。

打包不重新编码图片或声音，文件原字节保留；每个 ZIP 文件项有 CRC。单包最多 500MB，超过时减少勾选、分批操作。个别本地副本丢失时会在结果中报错，ZIP 仅包含成功读取的文件和缺项记录，不能将这种部分结果当完整备份。

界面“ZIP 已准备好，已请求浏览器下载”表示已交给浏览器，实际保存位置和完成状态以浏览器下载列表为准。“再次下载 ZIP”可在窗口关闭前重新下载同一包。


## 清单引用与素材库的联系

素材库是本项目共用的素材索引。单段创作点击“从素材库选择”，勾选后“用于当前分镜”；批量清单可以按 UUID、文件名、已登记编号或相对路径匹配。未逐镜指定参考时才使用“批量默认设置”的共用参考，明确写空数组表示不使用参考。单段与批量的参考列表互相独立；从批量模式打开素材库，按钮显示“用于批量共用素材”。

CSV / JSON 指定的路径从原目录读取，不拷贝到 `references`，不改名，不改写原清单。浏览器会保留用于预览、校验和恢复的工作缓存。支持目录句柄时，在提交请求前会重新读取原文件并核对 SHA-256；原文件发生变化或权限失效时会停止并要求重新读取、校验，避免悄悄用旧缓存生成。

优化结果统一保存为 `references/optimized/原素材ID/版本ID/原文件名`，所有素材必须与各自原文件同名。PNG/JPEG/WebP 保持真实编码；声音裁切保留支持的 WAV/MP3/M4A/AAC/OGG/FLAC 编码。无法保留格式时停止并提示外部处理，不伪装后缀。手动导入和清单路径引用采用同样规则，原路径文件不改动。

`project.json` 记录原始路径、别名、SHA-256、派生关系和实际使用的素材 ID；`reference-mapping.json` 同步导出原路径到当前有效路径的映射。生成请求使用映射后的素材字节。导出的制作 MD 也同时列出原清单引用与实际路径。已提交和已生成的镜头不会因素材优化而被重写。

## 选目录与备份

工作台“保存位置”显示浏览器提供的目录名，以及 references、clips、episodes、backups 等相对位置。浏览器不暴露完整盘符路径，界面不会拼出虚假的绝对路径；要确认绝对路径，可重新打开系统目录选择窗口。

每次选择输出目录，若发现 `references` 内有文件（含子目录），先显示数量、备份进度和位置，复制到 `backups/references_时间戳_随机标识/references/...`，逐文件核对 SHA-256，并输出 `manifest.json`。原目录保持原样。备份失败会停止后续写入。写入素材时如遇同路径不同内容，也会再备份旧文件并核验；旧版本的记录保留对应备份路径。不要删除这些备份后再将历史记录当作完整恢复源。


提示词、对白和素材目录可以递归引用其他本地文件。批量工作台点击“读取引用并展开”，先展示文本展开结果，再进入媒体校验流程；文本文件不作为图片或声音导入素材库。正文中的图片、声音链接与引用列共享素材去重和优化映射。完整写法见 [批量清单与路径引用](批量清单与路径引用.md)。


## 1.1 新增筛选、清空与自动关联

当前创作项目的素材库支持以下条件取交集：版本（当前有效 / 原始 / 优化派生 / 全部）、类型（图片与声音 / 图片 / 声音）、校验（全部 / 格式通过 / 待处理），以及文件名、编号或路径关键词。全选只选择当前可见结果，改变筛选会移除不可见勾选。

批量优化成功后默认显示优化版，隐藏其原图；未成功的原图继续显示问题。查看原图请切到“原始素材”，查看全部历史请切到“全部版本”。原图被隐藏不等于删除，也不等于已经通过内容审核。

“清空素材库”将当前创作项目的素材成员移入可恢复记录；本地原文件、优化文件、浏览器副本、已排队分镜及其引用和历史全部保留。“恢复已清空素材”可以恢复成员。“取消选择”只是取消批量勾选，两者不同。

工作台填写提示词中的完整文件名，点“自动关联素材库”可使用当前项目同名素材的有效优化版。多个来源同名时填写明确路径或手动选择；不凭角色名猜素材。自动关联仍检查每镜数量和声音总长。

导入结束时已保存文件。“选中结果并打开素材库”勾选本轮结果，便于批量优化、下载或用于分镜；“关闭结果”只关闭窗口，不改变现有勾选。来自单段参考上传框的导入会尝试填入当前分镜，超限则只导入并说明。

## 1.1.1 新增单段试听与试看

开始播放新的声音或视频，旧的一段自动暂停并保留播放位置。素材库试听、任务卡片、详情历史版本、整集试看共用此规则。关闭预览窗口、切换页面 / 创作项目或移除播放器后，隐藏媒体不会继续播放。无需手动逐个停止，也不会同时叠加几段声音。

## 1.1.3 原素材只引用及错误恢复（2026-10-02）

所有未修改素材只引用源文件，输出目录只写项目 / 映射记录。浏览器工作缓存用于预览和校验，不是references中的额外原件。优化版、裁切版才同名另存，以目录区分来源和版本；任何新文件名都不加哈希前缀。

“添加素材”会用浏览器文件选择器保存原件的只读句柄，提交时重新读取并核对哈希。CSV目录导入继续按清单路径读取；拖放也尽量保留句柄。兼容浏览器或仅File输入无法取得实际源路径 / 句柄时，不虚构盘符或复制原件，只使用已经选择的文件缓存，重开时必要的重新选择会提示。

报“原文件当前不可读取”：原件可能已被移动、替换、占用，或先前File状态失效。点击“重新选择原文件”定位当前文件；同名且哈希相同会复用已有ID。损坏格式或内容已变化仍需重新校验，不能靠重复点击强行通过。

报“目录保存未完成”：素材记录先保存在浏览器，暂停后续处理。释放占用或重新授权后点“重试目录保存”，仅补写未完成的优化文件与project / 映射记录，不重新导入；成功后可继续剩余项。英文底层状态不再直接占据结果列表。正在生成、仍有在途任务时不修改素材或重做。

旧版12位前缀是SHA-256摘要。旧记录升级保留ID、哈希、旧路径别名和历史尝试；旧文件只用于兼容恢复，不改名、不自动删除。新导入重新关联源文件后使用源路径。外部脚本如果只拼接文件名且没读取映射，旧前缀确实可能导致找不到；X-AI新任务按素材ID和有效路径定位，不要求用户改原CSV来匹配旧前缀。

## 1.1.4 目录文件反复报错（2026-10-02）

提示reference-mapping.json保存失败时，问题在目录记录，不是这一段声音格式。程序会重新获取目标句柄，最多尝试5次并回读SHA；短暂失败恢复后正常结束。批量逐项project.json保存保留，映射在本轮结束 / 停止统一刷新，未变化不重复写。

持续失败时素材已在浏览器保留，点“重试目录保存”只补保存，不重新导入。结果窗口显示待保存阶段；必要时关闭相关占用或重新选择输出目录。“下载处理记录”附本轮路径、打开 / 写入 / 提交 / 核验阶段、错误代码和尝试次数。权限拒绝、空间不足需处理对应原因。原文件不复制、不改名，优化版依旧同名独立目录。

## 1.1.5 查看任务进度

素材校验与优化仍使用本页独立进度窗口。素材入队生成后，在“任务与成片”查看实时阶段、下载字节、五点抽帧与完整解码提示。页面“刷新状态”不会重新导入素材、复制原件或重建收费任务。显示技术流程完成后仍需听审 / 试看内容。


## 1.1.6 生成下载阶段的故障

任务统计放到筛选 / 刷新右侧；阶段和时间展开查看。服务端completed但媒体下载失败显示“已生成 · 下载待恢复”，不要重做生成。点“重试下载”；本机网址自动走固定视频CDN的同源恢复。Pages点“下载帮助”设置配对连接器，或打开原视频下载后导入。素材格式通过、服务端生成、本地就绪与内容审核是不同阶段；原素材 / 同名优化映射和批量任务原编号保持。

## 1.2.0 小白版与专家版（2026-10-03）

小白版选择素材后自动开始校验，显示格式、大小、尺寸 / 比例、声音时长与重复项的检查说明和真实进度。图片不合规时自动等比缩放 / 补边并同名另存优化版，选入当前分镜。成功结果自动关闭，不必点“开始校验”“选中结果”“完成”。处理失败、声音需要决定裁切区间或目录不可写时显示具体待处理项，不能自动猜选区间。专家版仍提供完整计划、进度、结果与批量操作。

未修改素材继续只引用原件；优化结果只存references/optimized/原ID/版本ID/原文件名。PavoAI的＋按钮与@素材库入口可直接使用，三标签各自保留素材选择。发送的平台名称随当前模型选择更新。


## 1.2.2 运行期间准备下一镜

前一镜生成或冷却期间，可在工作台输入下一镜提示词并上传/选择素材。接收、格式校验与必要优化正常进行；本轮入队后显示待提交和预计等待。已经准备或发出的请求快照保持，不回写替换历史；未修改原素材继续只引用原件，优化素材保留原名和替换映射。


## 1.2.3 入队后准备下一镜

成功入队后提示词和本轮已选素材会自动清空；这些输入已保存在对应任务中，可在“详情与操作”查看。素材库、原文件与优化文件仍保留；需要复用时重新选择，平台/模型、时长、画幅等继续沿用。冷却期间也可接收入队并清空，排队任务到期自动提交。输入有误或保存失败时保留输入。

任务页右侧显示自检原因；原片保存后显示后台校验，下一独立镜头无需等待前片内容审核。网络恢复后自动接续；明确暂停和专家手动任务仍尊重你的选择。
