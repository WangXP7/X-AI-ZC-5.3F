# 素材导入、全图预览与批量操作

## 导入前先看校验清单

在素材库选择“添加素材”，或在创作表单选择 / 拖入参考文件。文件选好后先显示数量、总大小及待检查项目；这时尚未解码、导入或优化。点击“开始校验并导入”才开始执行。

|检查|规则与结果|
|---|---|
|可读取性|图片实际解码，声音实际读取媒体信息；损坏或不支持的文件单独报错，其余继续|
|大小|API 参考文件须小于 15MB；超限标为待处理，超过 150MB 的单文件不导入|
|图片|PNG/JPEG/WebP；宽高均为 256–5760；宽高比 0.4–2.5|
|声音|读取可播放性及真实时长，不识别台词；每镜声音最多 3 段、合计 2–12 秒，在分镜入队时检查|
|重复|计算 SHA-256；相同内容复用已有素材，同名但内容不同分别保留|
|分镜组合|图像最多 5 张、声音最多 3 段、声音总长和引用编号，在使用素材编排分镜 / 入队时校验|

尺寸、比例、格式等可以修正的问题不会丢弃原文件，而是在素材卡片显示原因。格式检查不能确认人物身份、服装、画面表达、对白或声音归属，仍需看图、听审或借助外部 AI。

## 查看批量进度

窗口显示当前文件、阶段、处理数量和进度条；结果分为完成、待处理、复用、跳过、失败。

- **完成当前项后停止**：先保存正在处理的这一项，再停止，不丢弃已完成结果。
- **继续剩余项**：只继续刚才尚未处理的文件；本轮计数从剩余项开始。
- **重试失败项**：只重试失败文件；坏文件可能需要先转换格式后重新选择导入。
- **选中本轮结果**：回到素材库，勾选本轮成功得到的素材；优化后可直接选中优化版。
- **下载本轮结果 ZIP**：直接下载这次的结果，避免优化后误下载仍然勾选的原图。
- **下载处理记录**：导出本轮逐项原因、素材路径及已计算的 SHA-256。

手动添加的文件会建立管理副本；清单按路径引用的原素材只读取，不复制到输出目录。优化结果与管理副本在有输出目录时落盘，没有选择目录时先存浏览器。若目录断开或失去权限，浏览器副本仍保留，窗口显示写入失败并停止后续项；先重新授权或下载备份。

## 全图和长条图

卡片按原比例完整显示，不以裁掉头脚的方式填满框。宽高比大于等于 2 的长横图在宽屏占两列；窄屏恢复单列。图片采用延迟解码，减少大量素材同时显示的负担。

点击图片打开全图窗口：**适应窗口** 显示完整图片；**原始尺寸** 按真实像素显示；加减按钮可缩放，放大后滚动查看。原始文件不会因预览而改动。

## 多选与批量优化

卡片左上角的复选框用于批量处理，和“用于当前分镜”分开。添加到素材库不会自动把所有文件用到当前镜头。通过创作表单导入时会尝试作为当前参考；超出单镜数量 / 声音总长限制时，只导入素材库并提示重新挑选。

可以全选、清空或一键选择待优化图片。点击“批量优化图片”后会先说明处理方式：

1. 图片等比缩放、按需要补边；路径引用的 PNG / JPEG / WebP 保留原格式和完整文件名，其他格式转换为 JPEG 并改为 .jpg 后缀。声音批量优化时列为跳过，需要单独指定裁切区间。
2. 图片优化画布控制在 256–2048 像素，并符合比例范围；极窄图通过补边满足要求，不先把短边放大而撑爆长边。
3. 每张另存并再次校验，记录 derivedFrom 和转换方式。原图与已提交任务、已生成历史保留。清单路径引用的原图会记录优化替代关系，新任务与尚未提交任务自动使用合格的优化版。
4. 同一原图已有相同且可读取的优化结果时复用；已合规的派生版本跳过。
5. 优化不会补出原本不存在的画面细节。结果仍需查看内容；技术合规的路径引用优化版会自动映射，不等于艺术审核通过。

## 批量下载

勾选文件 → **批量下载 ZIP**。只产生一个 ZIP 下载，避免浏览器逐个文件拦截；同名文件使用不同后缀，原名称、素材 ID、来源和 SHA-256 记录在包内的 `X-AI_素材清单.json`。

打包不重新编码图片或声音，文件原字节保留；每个 ZIP 文件项有 CRC。单包最多 500MB，超过时减少勾选、分批操作。个别本地副本丢失时会在结果中报错，ZIP 仅包含成功读取的文件和缺项记录，不能将这种部分结果当完整备份。

界面“ZIP 已准备好，已请求浏览器下载”表示已交给浏览器，实际保存位置和完成状态以浏览器下载列表为准。“再次下载 ZIP”可在窗口关闭前重新下载同一包。


## 清单引用与素材库的联系

素材库是本项目共用的素材索引。单段创作点击“从素材库选择”，勾选后“用于当前分镜”；批量清单可以按 UUID、文件名、已登记编号或相对路径匹配。未逐镜指定参考时才使用“批量默认设置”的共用参考，明确写空数组表示不使用参考。单段与批量的参考列表互相独立；从批量模式打开素材库，按钮显示“用于批量共用素材”。

CSV / JSON 指定的路径从原目录读取，不拷贝到 `references`，不改名，不改写原清单。浏览器会保留用于预览、校验和恢复的工作缓存。支持目录句柄时，在提交请求前会重新读取原文件并核对 SHA-256；原文件发生变化或权限失效时会停止并要求重新读取、校验，避免悄悄用旧缓存生成。

优化结果保存为 `references/原文件名`，PNG/JPEG/WebP 保持原后缀和实际编码。声音裁切在支持的格式内保留 WAV/MP3/M4A/AAC/OGG/FLAC 文件名与编码，编码器不可用时提示改用外部工具，不将 WAV 字节伪装成 MP3。改变图片格式必需改变扩展名时，会在处理说明中指出。不同原目录有同名文件、或原文件本就在目标 `references` 路径下时，优化版使用 `references/素材ID/原文件名`，防止互相覆盖或改写原文件。

`project.json` 记录原始路径、别名、SHA-256、派生关系和实际使用的素材 ID；`reference-mapping.json` 同步导出原路径到当前有效路径的映射。生成请求使用映射后的素材字节。导出的制作 MD 也同时列出原清单引用与实际路径。已提交和已生成的镜头不会因素材优化而被重写。

## 选目录与备份

工作台“保存位置”显示浏览器提供的目录名，以及 references、clips、episodes、backups 等相对位置。浏览器不暴露完整盘符路径，界面不会拼出虚假的绝对路径；要确认绝对路径，可重新打开系统目录选择窗口。

每次选择输出目录，若发现 `references` 内有文件（含子目录），先显示数量、备份进度和位置，复制到 `backups/references_时间戳_随机标识/references/...`，逐文件核对 SHA-256，并输出 `manifest.json`。原目录保持原样。备份失败会停止后续写入。写入素材时如遇同路径不同内容，也会再备份旧文件并核验；旧版本的记录保留对应备份路径。不要删除这些备份后再将历史记录当作完整恢复源。


提示词、对白和素材目录可以递归引用其他本地文件。批量工作台点击“读取引用并展开”，先展示文本展开结果，再进入媒体校验流程；文本文件不作为图片或声音导入素材库。正文中的图片、声音链接与引用列共享素材去重和优化映射。完整写法见 [批量清单与路径引用](批量清单与路径引用.md)。
