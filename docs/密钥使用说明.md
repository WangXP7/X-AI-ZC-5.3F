# 在 X-AI 中使用密钥

## 日常使用：不需要口令

这台电脑的默认密钥已经配置好。打开 X-AI 后，右上角显示 **系统默认密钥已启用**，不需要解锁、不需要运行取口令工具。

1. 打开左下角 **连接与密钥**，或点击右上角密钥状态。
2. 使用默认密钥时，直接点 **检查连接**，也可以直接创建任务。
3. 要换自己的密钥：在 **换用自己的密钥** 中粘贴以 `sk-` 开头的 KEY，点 **使用新密钥**。
4. 要切回默认密钥：点 **使用默认密钥**。

新输入的密钥仅在本次页面打开期间使用。关闭或刷新后恢复本机默认密钥；若当前部署没有默认配置，需要重新输入自己的密钥。输入成功后文本框会清空，防止误展示。

“已启用”代表页面已载入密钥，不代表账户认证、额度或所有接口都已验证。“检查连接”只请求模型列表，不创建视频，仍遵守至少 90 秒的认证请求间隔。

## 高级模式：需要时再展开

高级模式默认收起；每次重新打开设置窗口也会收起。普通换密钥无需使用其中的任何功能。

|需要做什么|操作|
|---|---|
|加密保存自己的 KEY|高级模式 → 输入新密钥 → 填 KEY → 勾选加密保存 → 设置并确认至少 12 位口令 → 加密保存并使用|
|使用保存过的加密副本|高级模式 → 使用已存密钥 → 选择文件来源 → 填入保存时的口令 → 解锁并使用|
|读取本机旧保险箱|高级模式 → 使用已存密钥 → 本机预存密钥 → 下载取口令工具，在原 Windows 用户下运行后粘贴口令|
|导入、备份或删除加密副本|高级模式 → 备份、导入与删除|
|停用本次会话的密钥|高级模式 → 停用当前密钥；刷新仍会载入本机默认配置|
|跨域失败或修改 API 地址|高级模式 → 高级连接设置；按提示使用可选本机连接器|

解锁口令不是 API KEY，也不会发送给 AgnesAI。自己设置的口令需要自行记住；忘记后只能重新输入 API KEY。导入文件只是候选，只有成功解锁才会替换浏览器中的加密副本。输错口令不会停用先前仍在使用的密钥。

本机旧保险箱的取口令工具为 `tools/copy-unlock-password.cmd`，原 `查看默认保险箱口令.ps1` 也继续保留。它们用于高级模式下的旧备份，不是日常使用的必需步骤。

## 保存位置与发布区别

- `private/default-access.json`：本机免口令使用配置，KEY 为 AES-GCM 密文，开启所需数据也存于该私有配置。因此持有此文件的人可以恢复 KEY；它不能当作可公开分享的密钥保护方案。
- `private/default-vault.json`：原来的口令加密备份。默认备份口令在 `%LOCALAPPDATA%\X-AI\default-vault-password.dpapi`，由 Windows 用户保护。
- 浏览器中的加密副本：由用户在高级模式主动保存，使用 PBKDF2 + AES-GCM，解锁口令不保存。
- 普通模式新输入的 KEY：只在内存中，不写项目 JSON、日志、Git 或浏览器持久存储。

本机自动使用配置是从已有保险箱一次性转换的，过程不写明文 KEY、不修改旧备份；转换脚本 `tools/prepare-local-default.mjs` 通过标准输入接收备份口令，不将秘密放入命令行参数。

`private/` 整个目录都被 `.gitignore` 排除。公开 GitHub Pages 不带私人默认密钥，访问者使用自己的 KEY。上传请使用 Git，不要把完整工作目录拖到网页上传。

## 常见提示

- **未配置默认密钥**：这是不含私人配置的发布版，可直接填写自己的 KEY。
- **默认密钥读取失败**：可点“重新读取默认密钥”；仍失败时用自己的 KEY，或恢复本机私有配置。
- **密钥格式错误**：确认复制的是以 `sk-` 开头的 API KEY；前后空格会自动清除。
- **解锁口令不正确**：只出现在高级模式；核对当前所选加密文件和它对应的口令。
- **连接失败**：检查网络、密钥权限及服务商状态；跨域问题在高级连接设置里处理。
- **错误提示在哪**：始终在设置弹窗底部的红色区域，字段也会标红。错误不会仅在背景右下角短暂闪过。
