# 发布与使用前需要准备什么

## 发布者

|信息 / 条件|用途|
|---|---|
|GitHub账号、仓库名|决定 `https://账号.github.io/仓库名/` 地址|
|GitHub登录凭证|在你本机推送，不能放进前端或Git|
|Git提交姓名和邮箱|本机Git已初始化；配置真实身份或自己的GitHub隐私邮箱后完成首次提交|
|Pages功能可用的仓库|一般使用公开仓库；私有仓库Pages取决于账户计划|
|可选自定义域名|如要使用，自己配置CNAME和DNS；本版不依赖域名|
|自己的API密钥|公开站点由使用者自己填写；需要口令加密备份时再在高级模式设置口令|

没有需要填入构建环境的API Secret。Pages仅提供静态文件。不要把默认密钥解锁口令写进GitHub Actions、Pages变量、JS、HTML、README或URL。

上传方式使用 `git push`，不要通过网页拖拽整个本地目录：WASM超过网页单文件25MB限制，工作目录还含Git已排除的私人密文。首次配置、提交、推送和Pages设置的完整命令在根目录README中。

## 每位使用者

1. 桌面版Chrome或Edge，以及有足够空间的本地输出目录。
2. 有权限调用Flash模型的AgnesAI账户/KEY、可用余额或配额。
3. 一镜一个动作的提示词、4–12秒时长、镜号和分组；对白单独指定。
4. PNG/JPEG/WebP参考图，声音片段；清单文件中引用的素材也要本地导入。
5. 如跨域失败，安装Python 3.10+、下载仓库里的 `tools/connector.py`，允许正确Pages来源，并在浏览器授权本地网络访问。
6. 如果需要语音克隆、复杂人物一致性修复或自动剧情审核，额外准备相应AI/音视频工具。X-AI会导出可复用的复核提示词。

## 推荐第一次试用

先做一个4秒文字任务，确认：提交返回video_id → 查询完成 → 下载 → 校验通过 → 本地目录出现MP4与报告。再用一张图、短声音测试参考模式，最后开启批量。

不要在旧生产脚本和本平台中同时使用同一账户，以免两个进程合计突破RPM或并发限制。

## 更新网站

```powershell
git add index.html src assets docs README.md
git commit -m "Update X-AI studio"
git push
```

如果修改了vendor、工具或其他文件，也有选择地加入。不要使用会覆盖Git仓库内容的“导出输出文件夹”作为仓库根目录。

上线后第一次用无痕窗口检查静态加载。原网站的浏览器本地数据不会自动跟随新的域名、端口或浏览器迁移，需从本地目录恢复项目。

## 公开发布前检查

- `git ls-files private .local` 无结果。
- `git ls-files` 不包含用户素材目录、实际生成视频、DPAPI文件、密钥、测试截图或日志。
- `vendor/ffmpeg-core/ffmpeg-core.wasm` 是普通Git文件，约32MB，不能被误换成Git LFS指针。
- 保留第三方许可证、源代码/构建来源说明。
- 在仓库子路径打开界面，检查所有资源没有错误地指向域名根目录。

本机默认密钥已配置为自动启用，不需要运行解锁脚本。`private/default-access.json` 包含免口令开启密文所需的数据，必须连同整个 private 目录留在本机，不能公开上传。Pages 访客直接输入自己的 KEY；口令解锁脚本仅供高级模式读取原来的私人备份。
