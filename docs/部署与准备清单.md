# 发布与使用前需要准备什么

## 1.2.7 本机保活更新

配套部署tools/background.py、process_lifetime.py、supervise.py以及更新的launch.py、local_runtime.py。Windows使用系统CIM和同一Python安装中的pythonw.exe隐藏启动，不注册计划任务、不请求管理员权限。若Windows拒绝系统启动，应保留明确错误，不能静默降级为仍会被启动器清理的“后台成功”。

启动X-AI.cmd默认开启每30秒检查的本机守护；重复启动复用本工程服务和守护。健康信息与.local/supervisor.json可验证pid、workspace、port、heartbeat以及killOnJobClose=false。守护重启只使用原端口；被其它程序占用时记录等待，不终止其它进程、不改Pages配置。

维护时 `python tools/supervise.py --stop` 只停止守护，已运行服务保留；最长一个检测周期确认停止。`python tools/launch.py --no-browser --no-watchdog` 用于一次性启动/隔离测试。正常启动器会再次启用保活。电脑注销或关机后需正常启动X-AI；这是本机进程，不宣称远程网页能越权启动本地程序。

发布网页1.2.7后才更新密钥界面逻辑。本机保活可先独立生效，原1.2.6 Pages已能使用恢复的媒体通道；无需为S06创建新任务。

## 1.2.6 Pages 自动取片发布清单

1. 本轮取代旧的“媒体通道只限本机同源”部署范围：指定Pages来源可用自动媒体凭证，API连接器仍独立。前端、media-relay.json及tools/media_session.py、serve.py、local_media.py必须配套更新；不能仅部署新的app.js。
2. 配置pageOrigins为精确HTTPS来源；当前为https://wangxp7.github.io。endpoint为已运行本机服务http://127.0.0.1:4183/，CSP已精确允许此地址。复制给其它部署时须维护配置；变更端口同步endpoint和CSP，不能改成任意来源或扫描端口。
3. 本机Python服务需要启动，更新Python模块后核对身份再重启。1.2.6已在当前机器4183启动验证。GitHub Pages不会运行Python；网页无法自行安装或启动一个未安装的本机服务。
4. 浏览器首次要求本地网络访问时，由使用者允许一次；程序不能代替授权或绕过拒绝。此权限不同于API配对码，允许后媒体自动握手，原来的API连接方式保持。已拒绝时等待权限恢复，恢复后自动检查。
5. 发布前运行build-runtime、build-design-doc，并执行Pages来源真实下载验证和回归。tests/pages-download-browser.mjs把本地代码映射到真实Pages来源，媒体仍经过真实浏览器、真实本机HTTP与真实CDN；这是发布前验证，不等于已发布。
6. 按仓库约定，Git推送/公开发布须用户另行授权。发布完成后确认在线版本1.2.6、刷新旧网页，检查原S04在原video_id下恢复，不新增生成任务。不要关闭有未知POST的窗口或改写其历史来强制更新。

当前静态站点1.2.5没有自动本机通道，单独重启本机Python不能修复旧网页。需要前后两部分同时生效。

## 1.2.5 间隔规则更新

替代旧的全局90秒配置：生成POST默认61秒，查询通常10秒，下载完成确认后立即开始。更新前端需重建模块图；更新tools/local_media.py或connector.py后需重启对应本机进程。连接器使用新的connector-submit-rate-v2.json，只有POST保留时间槽，GET不等待POST锁；响应暴露Retry-After，本机媒体错误JSON也保留该字段。不能删除来源/配对校验来提速。

验收重点为并发GET不绕过POST冷却、429渐增/成功渐减、Retry-After优先、正常排队不加罚，以及旧任务不重复创建。本机自检30秒保持，与服务器状态查询10秒是不同定时器。

## 1.2.4 发布及本机更新补充

1. 修改package.json版本后运行 `node tools/build-runtime.mjs`；该工具同步src/runtime-version.js、页面版本、所有src模块的import map和CSP精确哈希。新增src模块也须重建，不手工放宽script-src。
2. 先修改设计Markdown，再运行tools/build-design-doc.mjs重建离线HTML。
3. 本机tools/serve.py修改后，只重启身份核验通过的本工程服务，复用原端口；不终止其它项目进程。新版JS响应为no-store，页面刷新后验证dataset.runtimeVersion与版本一致。
4. 下载通道仍限同源本机页面和固定Agnes视频CDN；本轮未扩展为公开代理，未给不受信任来源自动访问本机的权限。远程静态站点受浏览器网络策略限制，不能把本机测试通过当成所有部署入口都已验证。
5. 回归需覆盖过期链接、流中断、原片回执正确/错误/被篡改、旧网络退避下离线恢复，以及真实本机通道读取已有视频；不为测试重复发起收费生成。
